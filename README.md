# 📱 WhatsApp Report Bot

A powerful WhatsApp bot system that allows users to report spam numbers automatically.

## ✨ Features

- 🤖 Automated WhatsApp bot
- 🪙 Coin-based reporting system
- 🔗 Referral program
- 📊 Live statistics dashboard
- 🔐 Secure authentication with email verification
- 📱 Mobile responsive design

- MongoDB Atlas account
- WhatsApp account
